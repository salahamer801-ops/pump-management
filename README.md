# مشروع تنظيم المضخات

تطبيق عربي (RTL) لإدارة المضخات والدياليات والحصص المائية اليومية، بواجهة موبايل أولًا ويعمل دون اتصال (Offline-first).

## المزايا
- وضع المدير: إدارة المضخة، المساهمون، الدياليات، الحصص، الوقود والرواسة، والحساب المالي.
- وضع المساهم: دفتر شخصي لعدة مضخات — الدورات، الأدوار، توزيع الحصص اليومية بالدقائق والساعات، الوقود والرواسة، والتقارير.
- عربي بالكامل مع دعم RTL، وتصميم أخضر/أبيض بسيط.
- قابل للتثبيت كتطبيق (PWA) ويعمل دون اتصال.

## التقنيات
React 19 · Vite · TypeScript · Tailwind CSS · lucide-react · vite-plugin-pwa

## التشغيل محليًا
```bash
npm install
npm run dev
```

## البناء للإنتاج
```bash
npm run build
```
